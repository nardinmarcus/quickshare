# Design Read

## Target and job
QuickShare 的默认应用壳层：首页（`/`，粘贴内容并发布）和管理后台（`/admin/pages`、详情、统计、API、审计）。锚点界面是首页和分享列表。访客模式为 operate：用户来完成任务，不是来被说服。

## Audience and usage scene
站长本人是主要使用者，登录后高频发布和管理；首页可切到公开模式，陌生访客也会来，所以首页要让首次访客一眼看懂怎么用，但不能做成营销页（用户回答：两者并重）。桌面为主，手机可用。

## Incumbent evidence
- `DESIGN.md`：声明「安静工作台」，中性色表面加单一青色强调，跟随系统明暗。
- `public/css/styles.css`（5569 行）：`:root` 与 `[data-theme="light"]` 令牌；遗留的 `cyber-*` 类名；加载了 Inter、Fira Code、Space Grotesk、Orbitron 四套字体。
- 2026-11-27 在本地内存模式下截取的渲染结果（首页、分享列表、详情、统计，1440 宽）。
- 观察到的问题：首页输入区只占视口约三分之一高，上下大片留白；后台导航、页面级操作、行内操作都是同一种灰色圆角按钮，分不出层级；筛选区占了列表卡片近一半高度；表格行稀疏，行内四个图标按钮没有标签；整体是灰底白卡片加青色点缀，没有产品自己的性格。

## Design authority state
`documented`，合同动作 `replace`。现有 `DESIGN.md` 与代码一致，但用户明确授权替换为全新视觉世界。

## Determined and missing elements
已定：功能与路由不变；四种内容类型；沙箱预览；跟随系统明暗；中文为主的混排。
待本轮决定：字体角色、配色策略、形状与深度、导航骨架、列表形态、文案语气。

## Reference intent
`none`。提供过 Cursor、Linear、Notion 三个候选，用户选择不绑定参考，由产品本身推导。

## Preserve, extend, replace, or create
`replace`。保留产品事实、内容、功能和可访问性约束；旧外观作为证据和反例。

## Functional and content invariants
- 首页：内容输入、类型自动识别、上传文件、Markdown 主题选择、发布设置（标题、描述、到期、访问方式、自定义或自动密码）、清除、安全预览、发布、发布回执（链接、密码、摘要）、发布未确认时的选择。
- 后台：统计、分享、API、审计、新建五个入口；搜索、类型、状态、日期、收藏筛选；排序；批量删除；行操作（打开、收藏、上下架、克隆、删除）；分页；详情里的历史版本、对比、恢复。
- 所有时间为北京时间。用户内容始终在沙箱 iframe 内渲染。

## Visual opportunity
让「发布一段代码」这件事本身有形状：把编辑区和结果放到视觉中心，用字体和结构而不是卡片和阴影建立辨识度。

## Constraints and anti-goals
- 第二轮新增：不要强烈的风格化（衬线纸面、粗描边硬投影、彩色分类色都被否决）；要极简黑白，靠排版和比例。
- 首页保持「居中输入区加折叠的发布设置」这一结构。
- 不要深色霓虹、赛博感、发光和渐变。
- 不要营销落地页的大标题、卖点卡片和 CTA 条。
- `hacker`、`cyberpunk`、`popart` 三套 UI 主题可以退役，新设计只维护一套视觉世界（实现阶段处理）。
- Markdown 内容主题在沙箱内独立渲染，不受影响。
- 预览只用系统字体栈；是否引入 Web 字体留到实现阶段校准。

## Clarification record
1. 主要不满 → 四项全选（没辨识度、布局和空间、层级和导航、精致度）。结果：四个方向都要重排骨架，不能只换皮。
2. 改动幅度 → 全新视觉世界。结果：模式定为 `replace`，方差调到 8。
3. 差异维度 → 视觉世界、结构与布局、气质与文案语气。结果：B、C、D 的字体、配色、骨架、语气都各不相同。
4. 参考对象 → 先选「你来提」，看过三个候选后选「都不用」。结果：`reference_mode` 为 `none`。
5. 明暗 → 继续跟随系统。结果：每个方向都给出两套配色，预览可切换。
6. 旧主题 → 可以砍掉。
7. 首页受众 → 两者并重。
8. 反目标 → 深色霓虹和营销落地页感。

9. 第二轮（否决第一轮后）：最接近的方向 → 一个都不接近；差在哪 → 风格太极端、骨架不对、不够精致高级；期望质感 → 极简黑白；首页骨架 → 保持现在的结构；后台骨架 → 你来定。结果：放弃衬线纸面、钴蓝工作室、彩色票根三个世界；四个方向统一为黑白，方差降到 5，首页都保持居中输入区加收起的设置，差异放在层级手段和后台骨架。

## Open facts
- 真实分享数量级未知（几十还是几千）。这会影响 D 的看板和 B 的登记簿在大量数据下是否成立。
- 手机端使用频率未知。

## Initial dials
- `variance` 5：第二轮后下调。用户要全新但克制的黑白，不要极端风格。
- `motion` 2：高频操作工具，动效只解释状态变化。
- `density` 5：极简留白优先，后台仍比现在紧凑。
