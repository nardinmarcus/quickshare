# Design System: QuickShare

<!-- SEED: approved before implementation; Impeccable must reconcile this contract with the built tokens and components. -->

## Overview

QuickShare 的应用壳层是一根居中的窄栏，两侧全是留白。首页和管理后台共用这根栏，访客和站长看到的是同一种安静的界面。

原则：

1. 内容在中心，外壳退后。页面上最重的东西是用户粘贴的内容和发布按钮。
2. 不画线。分区靠留白和填充色，不靠边框、分隔线和阴影。
3. 只有黑白灰。黑色只给最重要的动作和当前所在位置。
4. 状态用文字说清楚，不靠颜色区分。
5. 明暗两套同等对待，跟随系统。

适用范围：首页、登录页、密码解锁页、错误页和全部管理后台页面。Markdown 内容主题在沙箱 iframe 内独立渲染，不受本合同约束。`hacker`、`cyberpunk`、`popart` 三套 UI 主题退役。

## Colors

预览中已验证的代表值（实现时可在不改变关系的前提下校准）：

| 角色 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `bg` | `#ffffff` | `#0b0b0b` | 页面底色 |
| `fill` | `#f5f5f5` | `#181818` | 输入块、搜索栏、页签底、悬停行、类型方块 |
| `fill-strong` | `#ebebeb` | `#262626` | 填充块上的再一级强调（悬停行里的类型方块、按下态） |
| `ink` | `#111111` | `#f3f3f3` | 正文、标题、主按钮底、当前页签底 |
| `muted` | `#737373` | `#8f8f8f` | 次要文字、占位符、分组标题 |
| `on-ink` | `#ffffff` | `#0b0b0b` | 黑色块上的文字 |

规则：

- 没有品牌强调色。原来的青色整体移除。
- 危险操作（删除确认、错误提示）允许使用一档红色文字，色值在实现时校准，要求在 `bg` 和 `fill` 上都达到 4.5:1。成功状态用文字和图标表达，不引入绿色块。
- `muted` 放在 `fill` 上时对比度必须不低于 4.5:1；预览值在亮色下接近下限，实现时需要实测并在必要时加深。

## Typography

- 界面字体：`-apple-system, "SF Pro Display", "PingFang SC", "Noto Sans SC", sans-serif`。不加载 Web 字体；Inter、Space Grotesk、Orbitron 的加载移除。
- 等宽字体：`ui-monospace, "SF Mono", Menlo, monospace`，只用于用户粘贴的代码、分享 ID、密码和内容类型缩写。
- 页面标题：32–38px，字重 650，字距 -0.03em，行高 1.1。
- 正文和控件：15px，行高 1.5；中文长段落行高不低于 1.6。
- 次要信息：13px，`muted`。
- 代码输入区：13.5px，行高 1.9。
- 数字使用等宽数字对齐（`tabular-nums`）。
- 全界面最小字号 12px。

## Layout

- 一根居中的内容栏：首页 700px，后台 760px。视口再宽，栏也不变宽。
- 后台顶部是一行：左侧品牌名，中间胶囊页签（统计、分享、API、审计），右侧「新建」。这一行不带底线。
- 列表页的顺序固定：页面标题和数量、搜索栏（筛选控件收在搜索栏右端）、按日期分组的列表。
- 列表行高有两档：宽松 60px（两行），紧凑 40px（单行）。行与行之间没有分隔线。
- 首页垂直方向：品牌名和说明、输入块、设置摘要、按钮行、页脚。
- 分享详情页的栏宽为 960px。其他需要更宽空间的页面（统计图表、审计日志）也可以放宽到 960px，但保持居中和同样的顶部导航。这是唯一允许的结构变化。
- 窄屏：栏宽贴边留 16px；顶部页签可横向滑动；列表行的时间移到第二行；触控目标不小于 44px。最窄支持 360px。

## Elevation & Depth

没有阴影，没有边框，没有分隔线。层级只有三层：`bg`、`fill`、`fill-strong`。

例外只有三处，都出于功能需要：

- 键盘焦点环（2px，`ink`，带 2px 间隙）。
- 模态对话框背后的半透明遮罩。
- 沙箱 iframe 的边界：用 `fill` 底衬出内容区域，让用户内容和界面明显分开。

## Shapes

- 输入块：24px 圆角。
- 列表悬停行、对话框：16px 圆角。
- 类型方块：38px 见方，11px 圆角。
- 按钮、页签、搜索栏、小控件：胶囊（全圆角）。
- 图标：16px，1.5px 描边的线性图标，圆头圆角。不再使用 Font Awesome。

## Components

- **主按钮**：`ink` 底、`on-ink` 字、胶囊，高 46px，字重 600。一个视图里只有一个。
- **次按钮**：`fill` 底、`ink` 字、胶囊，高 46px。
- **文字按钮**：没有底色，`muted` 字，悬停时变 `ink`。
- **小控件**：高 32px 的胶囊，放在填充块里时用 `bg` 底。
- **输入块**：`fill` 底，24px 圆角，内部没有边框。聚焦时显示焦点环。
- **搜索栏**：高 46px 的 `fill` 胶囊，筛选小控件收在右端。
- **胶囊页签**：`fill` 底的容器，当前项是 `ink` 底、`on-ink` 字。
- **列表行**：左侧类型方块（等宽缩写：MD、HTML、SVG、MMD），中间两行（标题，字重 600；状态和访问量，`muted`），右侧时间。悬停或键盘聚焦时整行 `fill` 底，时间位置换成行操作图标。已下架的分享标题降为 `muted`。
- **分组标题**：13px `muted`，如「今天」「更早」。
- **设置摘要行**：居中的一行「发布设置」加当前取值，点开后在原位展开表单。
- **发布回执**：发布后在输入块的位置显示链接、密码和摘要，沿用填充块的形态。
- **对话框**：`bg` 底，16px 圆角，遮罩之上；危险操作的确认按钮用红色文字。
- **Toast**：`ink` 底、`on-ink` 字的胶囊，底部居中，不带进度条和彩色图标。

文案语气：简短、直接、中性。沿用现有文案，不加口语化改写。

动效：只有填充色和透明度的过渡，约 120ms。展开设置和显示回执可以有一次约 200ms 的高度过渡。用户要求减少动效时全部改为瞬时切换。

## Do's and Don'ts

要：

- 用留白分组，同一组内的间距明显小于组与组之间的间距。
- 让黑色稀少：每个视图只有主按钮和当前页签是黑色块。
- 用文字写出状态（公开、密码保护、已下架）。
- 行操作保持键盘可达，聚焦时和悬停时一样显示。

不要：

- 不要加边框、分隔线、阴影或渐变来「补层次」。
- 不要引入强调色、彩色状态标签或按内容类型上色。
- 不要把内容栏拉到全宽，也不要加侧边栏。
- 不要用卡片套卡片。
- 不要用发光、霓虹或任何营销页式的大标题和卖点区块。
