# Surface Brief
Selected direction: D — 单栏留白
Structural archetype: single-column-feed

Structural fingerprint:
- opening: 居中的大号品牌名和一句说明
- body: 浅灰圆角输入块，下方居中的设置摘要和胶囊按钮；后台是搜索胶囊加按日期分组的两行列表
- navigation: 后台顶部居中的胶囊页签
- ending: 首页页脚版权行；列表自然结束
- responsive: 栏宽贴边，其余不变

## Scope and visitor mode
目标是首页 `/` 和后台分享列表 `/admin/pages`，访客模式为 operate。登录页、密码解锁页、错误页、分享详情、统计、API、审计继承同一套系统，在实现时按本说明的规则推导，不另出方向。本说明不包含任何生产代码改动。

## Audience, job, and action
- 站长：高频粘贴内容并发布，然后在后台找到某个分享，复制链接、看密码、上下架或删除。
- 公开模式下的访客：第一次来，要一眼看懂「粘贴、发布、拿链接」。
- 首页的主要动作是「发布并生成链接」；后台列表的主要动作是找到一条分享并对它操作。

## Evidence and real content
- 文案、字段和功能来自 `views/index.ejs`、`views/admin-pages.ejs`、`views/partials/admin-nav.ejs`。
- 预览里的六条分享是示例数据，不是真实内容。
- 预览里链接只显示路径（`/view/<id>`），真实界面显示完整公开地址。
- 现状截图取自 2026-11-27 的本地内存模式实例。
- 缺口：真实分享数量级未知；手机端使用频率未知。

## Fidelity and calibration
- 原样保留：全部功能、路由、文案含义、表单字段、可访问性属性（`aria-*`、`role`、焦点管理）和现有 JS 依赖的元素 ID。
- 预览已验证、按意图实现：栏宽 700/760px；`bg`、`fill`、`fill-strong`、`ink`、`muted` 的关系和代表色值；24px 和 16px 圆角与胶囊；标题 32–38px 字重 650；列表行 60px；输入块内 13.5px 等宽字。
- 需要在真实渲染里校准：`muted` 在 `fill` 上的对比度（目标不低于 4.5:1）；危险操作的红色色值；非 Apple 平台上的标题字重（650 可能回落到 600 或 700）；暗色下 `fill` 和 `bg` 的差值是否足够分辨；动效时长（120ms 和 200ms 为起点）。

## Design foundation binding
全局规则在 `DESIGN.proposed.md`（批准发布后成为根目录 `DESIGN.md`）。本界面使用其中的全部颜色、字体、形状和组件定义，不新增令牌。没有采用外部参考。

## System lock and allowed variation
已锁定，实现时不得自行替换：

- 字体角色：系统无衬线做界面，等宽只给代码、ID、密码和类型缩写。
- 颜色与材质：黑白灰，两级填充，没有强调色；红色只给危险操作的文字。
- 间距、形状、深度：没有边框、分隔线和阴影；24px/16px 圆角和胶囊。
- 组件与状态语言：胶囊按钮、填充输入块、类型缩写方块、悬停行填充。
- 图标：16px、1.5px 描边线性图标。
- 动效：只有填充色和透明度过渡，以及展开时的一次高度过渡。
- 文案语气：沿用现有文案，简短中性。
- 结构：居中单栏加顶部胶囊页签。

允许的变化：详情、统计、审计等需要更宽内容的页面可以把栏放宽到 960px。除此之外不得引入侧边栏、全宽表格或卡片网格。如果某个功能在单栏里确实放不下，先提出来，不要悄悄改结构。

## Chosen direction and memorable moment
单栏留白：首页和后台是同一根窄栏，没有一条线。让人记住的是这种一致和安静：从首页粘贴发布，到后台找到那条分享，视线始终落在屏幕中间的同一个位置。

## Structure and responsive behavior
首页，自上而下：

1. 品牌名「QuickShare」和「粘贴代码，一键分享」，居中。
2. 输入块：等宽文字输入区；块内底部左侧是识别出的内容类型，右侧是「上传文件」。内容为 Markdown 时，主题选择器出现在输入块下方、设置摘要上方。
3. 设置摘要行：「发布设置」加当前取值（访问方式、有效期、标题），点开后原位展开为表单：标题、描述、到期日期、访问方式、密码模式。
4. 按钮行，居中：「清除」（文字按钮）、「安全预览」（次按钮）、「发布并生成链接」（主按钮）。
5. 状态行和错误信息在按钮行下方居中。
6. 安全预览和发布回执在同一栏内、输入块下方出现。
7. 页脚版权行。

后台分享列表，自上而下：

1. 顶部行：品牌名、胶囊页签（统计、分享、API、审计）、「新建」。
2. 标题「分享」、数量和「北京时间」。
3. 搜索栏，右端是类型、状态、收藏三个筛选小控件；日期筛选和「导出清单」收进一个「更多」入口。
4. 按日期分组的列表（今天、昨天、本周、更早）；每行是类型方块、标题、状态与访问量、时间。密码保护的行在第二行显示密码。
5. 分页放在列表末尾，文字形式。

窄屏：栏宽贴边留 16px；页签横向滑动；行操作改为点行后在行下方展开；触控目标不小于 44px。

## Components, states, and motion
- 输入块：空（显示占位符）、有内容、聚焦（焦点环）、拖入文件、处理中。
- 内容类型小控件：自动识别结果；四种类型。
- 设置摘要：收起、展开；展开为一次约 200ms 的高度过渡，可随时打断，减少动效时瞬时切换。
- 发布按钮：默认、悬停、聚焦、处理中（`aria-busy`）、禁用。
- 发布状态：准备发布、发布中、已发布、失败、上次发布未确认（保留现有的两个选择）。
- 发布回执：链接、密码（如有）、摘要、打开、复制、继续创建。
- 列表行：默认、悬停或聚焦（`fill` 底并显示操作）、已选中（批量）、已下架（标题降为 `muted`）、收藏。
- 行操作：打开、收藏、上下架、克隆、删除；删除走确认对话框。
- 列表空状态：还没有分享；没有符合条件的分享（带清除筛选的入口）。
- 悬停行：指针进入 → 行底变为 `fill` → 约 120ms 颜色过渡 → 离开即恢复 → 减少动效时瞬时。

## Assets and implementation consequences
- 需要一套 16px 线性图标（预览里用到约 20 个），替换 Font Awesome 的 CDN 引用。
- 移除 Google Fonts 的四套字体加载。
- `public/css/styles.css` 的令牌和组件样式需要整体重写；`cyber-*` 类名可以在实现时一并更名，但要同步更新依赖它们的 JS 和测试。
- `UI_THEME` 的三套可选主题退役，涉及 `config.js`、`public/js/theme.js`、相关 CSS 和文档。
- 列表按日期分组需要在模板里按北京时间分组，不需要改数据库。
- 测试里对类名、DOM 结构和文案的断言会受影响，实现时要一起更新。

## Constraints and anti-goals
- 不要深色霓虹、赛博感、发光和渐变。
- 不要营销落地页的大标题、卖点卡片和 CTA 条。
- 不要强烈的风格化：衬线纸面、粗描边硬投影、彩色分类色都已被否决。
- 首页保持「居中输入区加折叠的发布设置」。
- 用户内容始终在沙箱 iframe 内渲染；`GET /view/:id` 保持只读。
- 仍然是 EJS 加原生 CSS 和 JS，不引入前端框架。

## Unresolved decisions
2026-11-27 用户已逐条确认，以下均为已定：

1. **排序保留。** 类型、创建时间、状态三种排序都保留。搜索栏右端加一个「排序」小控件；按创建时间排序时列表按日期分组，按类型或状态排序时改为按该字段分组。
2. **批量删除改为「选择」模式。** 默认不显示复选框；点「选择」后每行左侧的类型方块换成勾选框，栏底出现操作条（已选数量、删除所选、取消）。
3. **详情页放宽到 960px。**
4. **提供紧凑行高。** 列表有「宽松 / 紧凑」两档：宽松 60px 两行，紧凑 40px 单行（标题、状态、访问量、时间排成一行）。选择记在浏览器本地。
5. **日期筛选和导出清单** 收进搜索栏右端的「更多」入口（用户未单独回复，按建议执行；如不合适请指出）。
